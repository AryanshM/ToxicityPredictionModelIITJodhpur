# VisionX Toxicity Prediction Model

## Overview
Trained using 200+ biochemical features extracted from molecular formulas, this machine learning model predicts the toxicity of chemical compounds. The system offers an interactive web interface for fast and accurate predictions.

## Features
- 200+ biochemical features extraction from molecular formulas
- Machine learning-based toxicity prediction
- Interactive Streamlit web interface
- Fast and accurate predictions
- Pickle-based model serialization for seamless deployment

1. Initialize and clone repo
2. Upload the molecular compound dataset or enter molecular formulas.
3. View toxicity prediction results.

## Dependencies
- Python 3.x
- Streamlit
- Scikit-learn
- TensorFlow
- RDKit
- Pandas
- NumPy
- Pickle
